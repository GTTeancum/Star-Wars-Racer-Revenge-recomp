## Project Overview

Static recompilation of Star Wars: Racer Revenge (PS2) to native PC using [PS2Recomp](https://github.com/ran-j/PS2Recomp). The recompiler translates MIPS R5900 instructions from the PS2 ELF into C++ that links against a runtime providing PS2 hardware abstractions (memory, GS, DMA, SPU2, pad, CDVD, VU, IPU).

| Load address | `0x100000` |

## Build

### Prerequisites
- Visual Studio 2022 (MSVC 14.44+)
- CMake 4.3+
- PS2Recomp submodule (`tools/PS2Recomp`)

### Regenerate recompiled code (only if ELF analysis changes)
```
tools/PS2Recomp/build/ps2xAnalyzer/Release/ps2_analyzer.exe SLUS_202.68 config/racer_revenge.toml
tools/PS2Recomp/build/ps2xRecomp/Release/ps2_recomp.exe config/racer_revenge.toml
```

### Build
```
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Release --parallel
```

### Run
```
build/Release/racer_revenge.exe [path/to/SLUS_202.68]
```
If no path given, looks for `SLUS_202.68` next to the executable.

## Known Issues

### Large functions excluded from build
7 generated files >2MB excluded (MSVC uses 3+ GB RAM per file). Stub implementations provided.
See `CMakeLists.txt` EXCLUDE_LARGE_FILES and `src/large_function_stubs.cpp`.

### Missing function addresses (4 unique)
| Address | Type | Notes |
|---|---|---|
| 0x3c7b80 | Data segment | Vtable/function pointer — runtime resolves via fallback |
| 0x2f7468 | Interior label | Inside sub_002F7430 |
| 0x308df8 | Interior label | Inside sub_00308D08 |
| 0x30451c | Interior label | Inside sub_00304448 |

### Giant function: sub_0031D200
Analyzer treats 0x31D200–0x3D5A00 (748KB) as one function. Likely runs into data segment.
Skipped in TOML — generates 2.1GB C++ output otherwise.

## Asset Tool (Legacy)
`rr_asset_tool.py` — Python GUI tool for:
- RES archive extraction
- PSG → OBJ/FBX (models)
- PST → TGA (textures, including IPU-compressed)
- SCB track assembly

The IPU decoder work from previous sessions is preserved in this tool and may be ported to C++ for the runtime's IPU implementation.
